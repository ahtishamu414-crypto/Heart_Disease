# Heart_Disease
🫀 AI-powered heart disease risk prediction using Logistic Regression, SVM, Random Forest &amp; XGBoost — FastAPI backend + responsive HTML/CSS frontend with 4-model consensus system
CardioGuard predicts the likelihood of heart disease based on 13 clinical features such as age, blood pressure, cholesterol, ECG results, and chest pain type. It trains 4 classification models — Logistic Regression, SVM, Random Forest, and XGBoost — and presents a consensus-based risk assessment through an interactive web UI.
This project is part of Task 4: Disease Prediction from Medical Data and demonstrates a complete end-to-end ML pipeline from data preprocessing to deployment.
